Right View of a Binary Tree

The Right View of a Binary Tree is a classic binary tree problem based on Level Order Traversal (BFS) or DFS with depth tracking. For every level, select the rightmost node visible from the right side.

Recommended pattern: Process one level at a time with BFS and add the last node at each level.

1. Problem Understanding

Consider the following binary tree:

          1
        /   \
       2     3
      / \   / \
     4   5 6   7
    /
   8

The right-side view for this tree is also illustrated by the GeeksforGeeks level-order traversal problem.

Looking at the tree from the right side, the visible nodes are:

  • Level 0: 1
  • Level 1: 3
  • Level 2: 7
  • Level 3: 8

Therefore, the answer is:

[1, 3, 7, 8]

Node 8 is visible even though it is a left child. It is the only node at the deepest level, so it is visible from the right.

Important conditions

  • The tree contains between 1 and 100,000 nodes.
  • Node values range from 0 to 10^9.
  • The tree is not necessarily complete or balanced.
  • Return an ArrayList<Integer> using the given solve(TreeNode A) signature.

2. Brute-Force Approach

A simple approach is to perform a separate traversal for every level and find the rightmost node at that level.

Logic

  1. Find the height of the tree.
  2. For each level, traverse the tree from left to right.
  3. Keep updating the answer for that level whenever a node is found.
  4. The last node found at that level is the rightmost node.

This works, but repeatedly visits nodes while processing different levels.

Java implementation

import java.util.*;

public class Solution {

    public ArrayList<Integer> solve(TreeNode A) {
        ArrayList<Integer> result = new ArrayList<>();

        if (A == null) {
            return result;
        }

        int height = getHeight(A);

        // Process every level separately.
        for (int level = 1; level <= height; level++) {
            int[] rightmost = new int[1];

            // Find the last node encountered at this level.
            findRightmost(A, level, rightmost);

            result.add(rightmost[0]);
        }

        return result;
    }

    private int getHeight(TreeNode root) {
        if (root == null) {
            return 0;
        }

        return 1 + Math.max(
            getHeight(root.left),
            getHeight(root.right)
        );
    }

    private void findRightmost(
        TreeNode root, int level, int[] rightmost
    ) {
        if (root == null) {
            return;
        }

        if (level == 1) {
            rightmost[0] = root.val;
            return;
        }

        // Visit left first, then right.
        findRightmost(root.left, level - 1, rightmost);
        findRightmost(root.right, level - 1, rightmost);
    }
}

Time complexity

\(O(NH)\), where \(N\) is the number of nodes and \(H\) is the tree height. We may traverse most of the tree again for every level.

Auxiliary space

\(O(H)\) for recursive calls, excluding the returned result.

For a skewed tree, \(H=N\), so the time complexity becomes \(O(N^2)\). This is too slow for the maximum constraint of 100,000 nodes.

3. Optimized Approach — Level Order Traversal (BFS)

The best practical approach is BFS using a queue. Instead of traversing the tree repeatedly, process every node exactly once.

Intuition

Level Order Traversal processes nodes level by level. If children are inserted into the queue from left to right, the last node processed at each level is the rightmost node. 

          1
        /   \
       2     3
      / \   / \
     4   5 6   7
    /
   8
  • Level 1: [1] → select 1
  • Level 2: [2, 3] → select 3
  • Level 3: [4, 5, 6, 7] → select 7
  • Level 4: [8] → select 8

Result: [1, 3, 7, 8]

Java solution — recommended for interviews

import java.util.*;

public class Solution {
    public ArrayList<Integer> solve(TreeNode A) {
        ArrayList<Integer> result = new ArrayList<>();

        // Handle an empty tree.
        if (A == null) {
            return result;
        }

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(A);

        while (!queue.isEmpty()) {

            // Number of nodes at the current level.
            int size = queue.size();

            for (int i = 0; i < size; i++) {
                TreeNode current = queue.poll();

                // The last node processed at this level is the rightmost node.
                if (i == size - 1) {
                    result.add(current.val);
                }

                // Add left child before right child.
                if (current.left != null) {
                    queue.offer(current.left);
                }

                if (current.right != null) {
                    queue.offer(current.right);
                }
            }
        }

        return result;
    }
}

Understanding the important lines

int size = queue.size();

Captures how many nodes belong to the current level. Save this number before adding the next level's children.

if (i == size - 1)

The loop processes nodes from left to right. The final node has index size - 1, so its value is added to the answer.

Add the left child before the right child

if (current.left != null) {
    // Queue children from left to right.
    queue.offer(current.left);
}
if (current.right != null) {
    queue.offer(current.right);
}

This maintains left-to-right ordering within each level, making the last node the rightmost one.

5. Complexity Analysis

Let \(N\) be the number of nodes, \(H\) the height, and \(W\) the maximum number of nodes at any level.

Approach Time complexity Auxiliary space
Brute force\(O(NH)\)\(O(H)\)
Optimized BFS\(O(N)\)\(O(W)\) for the queue
  • Brute force: Nodes may be revisited once for each level.
  • BFS: Every node enters and leaves the queue once, giving \(O(N)\) time.
  • BFS space: The queue can hold nodes from the current and next levels, requiring up to \(O(N)\) space in the worst case. The output array requires an additional \(O(H)\) space and is excluded from auxiliary space.

6. Alternative Optimized Approach — DFS

You can also solve this using Depth First Search, visiting the right child before the left child. The first node encountered at each depth is the rightmost visible node. 

import java.util.*;

public class Solution {
    private ArrayList<Integer> result = new ArrayList<>();

    public ArrayList<Integer> solve(TreeNode A) {
        result.clear();
        dfs(A, 0);
        return result;
    }

    private void dfs(TreeNode node, int depth) {
        if (node == null) {
            return;
        }

        // The first node visited at this depth is visible.
        if (depth == result.size()) {
            result.add(node.val);
        }

        // Visit right first so the rightmost node is found first.
        dfs(node.right, depth + 1);
        dfs(node.left, depth + 1);
    }
}

Both BFS and DFS take \(O(N)\) time. However, DFS uses \(O(H)\) recursive stack space and can cause a stack overflow for a highly skewed tree with 100,000 nodes. For this constraint, iterative BFS is the safer recommendation.

9. Interview Preparation Notes

Pattern to remember: Binary Tree + BFS + Level Size Tracking.

Common mistakes

  • Adding every node instead of only the last node at each level.
  • Calculating queue.size() repeatedly inside the loop instead of storing the current level size.
  • Assuming the right view contains only right children.
  • Using recursive traversal without considering the maximum tree depth.

Likely interviewer follow-ups

  • Can you solve it using DFS? Yes. Visit right before left and record the first node at each depth.
  • What if the tree is left-skewed? Every node is visible from the right because each level has only one node.
  • Can we solve it in \(O(N)\) time? Yes. BFS or DFS visits every node once.

10. Final Recommendation

Use iterative BFS with a queue for this problem.

  • Time: \(O(N)\)
  • Auxiliary space: \(O(N)\) worst case
  • Core intuition: Process one level at a time and add the last node of each level.

This is simple to explain, efficient for 100,000 nodes, and a strong interview-ready solution.
