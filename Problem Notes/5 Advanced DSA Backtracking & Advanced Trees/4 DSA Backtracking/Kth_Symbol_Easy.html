K-th Symbol — Easy

This classic recursion and bit-manipulation problem can be solved by generating each row, or more efficiently by following the requested symbol's parent.

1. Problem Understanding

Row 1 contains only 0. To generate each next row, replace every symbol as follows:

  • 0 becomes 01.
  • 1 becomes 10.

Return the symbol at zero-based index B in row A.

The first four rows of the generated symbol sequence
RowSequence

Examples

Example 1

Input: A = 3, B = 0

Row 3 is 0110. The symbol at index 0 is 0.

Output: 0

Example 2

Input: A = 4, B = 4

Row 4 is 01101001. The symbol at index 4 is 1.

Output: 1

Constraints

  • \(1 \le A \le 20\)
  • \(0 \le B < 2^{A-1}\)

Each row contains twice as many symbols as the previous row. Therefore, row \(A\) contains \(2^{A-1}\) symbols.

2. Brute Force Approach — Generate Every Row

Intuition

Construct the entire row until row A is reached, then return the character at index B.

Algorithm

  1. Start with the string "0".
  2. For every next row, traverse the previous row.
  3. Append "01" for 0, or "10" for 1.
  4. Repeat until row A is generated.
  5. Return the character at index B as an integer.

Java code — Brute Force

public class Solution {
    public int solve(int A, int B) {
        String row = "0";

        // Generate rows from row 2 up to row A.
        for (int i = 2; i <= A; i++) {
            StringBuilder nextRow = new StringBuilder();

            // Replace each symbol according to the given rule.
            for (int j = 0; j < row.length(); j++) {
                if (row.charAt(j) == '0') {
                    nextRow.append("01");
                } else {
                    nextRow.append("10");
                }
            }

            row = nextRow.toString();
        }

        // Convert the character at index B into an integer.
        return row.charAt(B) - '0';
    }
}

Complexity analysis

  • Time: \(O(2^A)\), because we generate all symbols in the final row.
  • Auxiliary space: \(O(2^A)\), because we store the generated rows.

This works for the given constraints, but it creates many symbols even though only one is needed.

3. Optimized Approach — Recursion

Intuition

Instead of generating the entire row, find the required symbol by looking at the previous row. Each symbol produces two children: the left child is at an even index, and the right child is at an odd index.

Parent symbols and their left and right children
Parent symbolLeft child (even index)Right child (odd index)
001
110
  • If B is even, the required symbol is the same as its parent.
  • If B is odd, the required symbol is the opposite of its parent.
  • The parent is at index B / 2 in row A - 1.

Algorithm

  1. Base case: if A == 1, return 0, because row 1 contains only 0.
  2. Find the parent by recursively calling solve(A - 1, B / 2).
  3. If B is even, return the parent unchanged.
  4. If B is odd, flip the parent using 1 - parent.

Optimized Java code

public class Solution {
    public int solve(int A, int B) {
        // Row 1 contains only the symbol 0.
        if (A == 1) {
            return 0;
        }

        // Find the parent symbol in the previous row.
        int parent = solve(A - 1, B / 2);

        // At an even index, the symbol matches its parent.
        if (B % 2 == 0) {
            return parent;
        }

        // At an odd index, the symbol is the opposite of its parent.
        return 1 - parent;
    }
}

Why does 1 - parent work?

A symbol can only be 0 or 1:

  • If parent = 0, then 1 - 0 = 1.
  • If parent = 1, then 1 - 1 = 0.

Therefore, 1 - parent flips the symbol. We do not need to build any rows or use a StringBuilder.

5. Complexity Analysis

Time and auxiliary space complexity by approach
ApproachTime complexityAuxiliary space
Brute force\(O(2^A)\)\(O(2^A)\)
Optimized recursion\(O(A)\)\(O(A)\)

Optimized time complexity: \(O(A)\)

Each recursive call decreases A by one. We make at most A calls, and each call performs constant-time operations.

Optimized auxiliary space: \(O(A)\)

The recursion stack stores at most A calls. We do not store the rows themselves. The optimized recursive solution avoids generating unnecessary symbols.

8. Interview Preparation Notes

Key concept to remember

The important pattern is recursion by finding the parent element. When a sequence is constructed from the previous sequence, ask:

  1. Which previous element produced the element I need?
  2. Does the new element remain the same or change?
  3. Can I repeat this process until I reach a simple base case?

Here, the parent index is B / 2, and the symbol flips only when B is odd.

Common mistakes

  • Generating the entire row, which is unnecessary when only one symbol is requested.
  • Ignoring zero-based indexing: index 0 is the first symbol.
  • Using the wrong parent index: use B / 2 with integer division.
  • Forgetting the flip condition: odd indices must invert their parent's symbol.
  • Missing the base case: recursion must stop at row 1.

Likely interview follow-up questions

Q1. Why do we divide B by 2?

Every parent produces two children. Their indices are 2 * parentIndex and 2 * parentIndex + 1. Both children therefore have the same parent at index B / 2.

Q2. Can we solve it iteratively?

Yes. Start with 0 and flip the result for every odd index encountered while repeatedly dividing B by 2.

Q3. Can we solve it using bit manipulation?

Yes. The answer equals the parity of the number of set bits in B. If B contains an odd number of set bits, return 1; otherwise, return 0.

Q4. Why is recursion a good fit?

Every symbol depends on one symbol in the previous row. We can reduce the problem to a smaller instance until reaching row 1.

9. Final Recommendation

Use the optimized recursive approach in an interview. It is short, easy to explain, and avoids constructing the rows.

  • Time complexity: \(O(A)\)
  • Auxiliary space: \(O(A)\)
Find the parent's symbol at index B / 2. Keep it for an even index; flip it for an odd index.

That observation is the key to solving the entire problem.
