Java Algorithm Guide

Generate Subsets

Generate every possible subset of a sorted array of distinct integers using bit manipulation or include/exclude backtracking.

Recommended pattern: At each index, include the element, explore, undo that choice, and then explore without it.

1. Problem Understanding

You are given an array A containing distinct integers in increasing order. Return all possible subsets of its elements.

For example, if A = [1, 2, 3], the subsets are:

  • The empty subset: []
  • Subsets with one element: [1], [2], [3]
  • Subsets with two elements: [1, 2], [1, 3], [2, 3]
  • The subset with all elements: [1, 2, 3]

There are \(2^N\) possible subsets for an array of size \(N\), because each element has two choices: include it or exclude it. For \(N = 3\), the total is \(2^3 = 8\).

Important conditions

  • The empty subset must be included.
  • Every element is distinct.
  • The output can be returned in any order.
  • The input array is already sorted in increasing order.

2. Brute Force Approach — Bit Manipulation

Represent every subset using a binary number. For an array of size N, check all numbers from 0 to 2^N - 1. For each number, inspect each bit; if a bit is 1, include the corresponding array element in that subset.

For A = [1, 2, 3]:

Binary Selected elements Subset
000None[]
0011[1]
0102[2]
0111, 2[1, 2]
1003[3]
1011, 3[1, 3]
1102, 3[2, 3]
1111, 2, 3[1, 2, 3]

Java code — Bit Manipulation

import java.util.*;

class Solution {
    public ArrayList<ArrayList<Integer>> subsets(ArrayList<Integer> A) {
        ArrayList<ArrayList<Integer>> result = new ArrayList<>();

        int n = A.size();
        int total = 1 << n; // Total subsets = 2^n

        // Generate every possible bitmask.
        for (int mask = 0; mask < total; mask++) {
            ArrayList<Integer> subset = new ArrayList<>();

            // Check whether each element should be included.
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {
                    subset.add(A.get(i));
                }
            }

            result.add(subset);
        }

        return result;
    }
}

Complexity analysis

  • Time: \(O(N \times 2^N)\), because we examine up to \(N\) bits for each of the \(2^N\) subsets.
  • Auxiliary space: \(O(N)\) for constructing one subset, excluding the returned output.
  • Output space: \(O(N \times 2^N)\) to store all subsets.

This solution works efficiently within the given constraints. Recursion provides another natural way to understand the problem.

3. Optimized Approach — Backtracking

For every element, make two choices: include it or exclude it. Process the array one element at a time. When the index reaches the end of the array, save the current subset.

Algorithm

  1. Create an empty result list and an empty currentSubset.
  2. Start the recursive function at index 0.
  3. If index == A.size(), save a copy of currentSubset and return.
  4. Include the current element and recursively process the next index.
  5. Remove the current element to undo the previous choice. This is called backtracking.
  6. Recursively process the next index without including the current element.
  7. Return the result after all choices have been explored.

Java solution — Backtracking

import java.util.*;

class Solution {
    public ArrayList<ArrayList<Integer>> subsets(ArrayList<Integer> A) {
        ArrayList<ArrayList<Integer>> result = new ArrayList<>();
        ArrayList<Integer> currentSubset = new ArrayList<>();

        // Start exploring choices from the first array element.
        backtrack(A, 0, currentSubset, result);

        return result;
    }

    private void backtrack(
        ArrayList<Integer> A,
        int index,
        ArrayList<Integer> currentSubset,
        ArrayList<ArrayList<Integer>> result
    ) {
        // Save a copy once every element has been considered.
        if (index == A.size()) {
            result.add(new ArrayList<>(currentSubset));
            return;
        }

        // Choice 1: include the current element.
        currentSubset.add(A.get(index));

        // Explore subsets that include this element.
        backtrack(A, index + 1, currentSubset, result);

        // Undo the include choice before exploring the exclude branch.
        currentSubset.remove(currentSubset.size() - 1);

        // Choice 2: exclude the current element.
        backtrack(A, index + 1, currentSubset, result);
    }
}

Understanding the important lines

1. Base condition

if (index == A.size()) {
    result.add(new ArrayList<>(currentSubset));
    return;
}

When index reaches the array's length, all elements have been considered. Save the current subset and return. The empty subset is also generated naturally when every element is excluded.

2. Include the current element

currentSubset.add(A.get(index));
backtrack(A, index + 1, currentSubset, result);

Add the element at the current index and explore all subsets that include this choice.

3. Backtrack

currentSubset.remove(currentSubset.size() - 1);

After exploring the include choice, remove the element so the next recursive call starts with the correct subset.

4. Exclude the current element

backtrack(A, index + 1, currentSubset, result);

Move to the next index without adding the current element. This explores all subsets that exclude it.

Why is this approach correct?

Every element has exactly two choices: include or exclude. The recursion explores both choices at every index, so every possible combination is generated. Because the index always moves forward, no element can be selected more than once. Since the input elements are distinct, each subset is generated exactly once.

4. Dry Run of the Optimized Solution

Input: A = [1, 2, 3]. The recursion explores the include branch first, then the exclude branch.

  1. Index 0, current subset []: include 1.
  2. Index 1, current subset [1]: include 2.
  3. Index 2, current subset [1, 2]: include 3.
  4. Index 3, current subset [1, 2, 3]: reach the base case, save the subset, and return.

After reaching [1, 2, 3], the recursion returns and removes 3. It then explores [1, 2] without 3, backtracks further, and continues through the remaining include/exclude choices.

5. Complexity Analysis

Both approaches have the same asymptotic complexity.

Approach Time complexity Auxiliary space Output space
Bit manipulation\(O(N \times 2^N)\)\(O(N)\)\(O(N \times 2^N)\)
Backtracking\(O(N \times 2^N)\)\(O(N)\)\(O(N \times 2^N)\)

Why is backtracking \(O(N \times 2^N)\)?

  • There are \(2^N\) possible subsets.
  • Saving a subset requires copying up to \(N\) elements.
  • Therefore, the total time spent generating and storing subsets is \(O(N \times 2^N)\).

The recursion depth is at most \(N\), and currentSubset can contain at most N elements. Thus, auxiliary space is \(O(N)\), excluding the output.

The output itself requires \(O(N \times 2^N)\) space. This is unavoidable because the problem asks us to return every subset.

6. Edge Cases

Input Expected behavior
[5]Generates [] and [5]

[-2, 0]Handles negative and zero values normally

The input cannot be empty under the given constraints. However, if an empty array were allowed, this implementation would correctly return a list containing just the empty subset: [[]].

8. Interview Preparation Notes

Key pattern: Recursion + Backtracking, using the include/exclude technique.

Common mistakes

  1. Adding currentSubset directly to result: Always save new ArrayList<>(currentSubset) so each result is an independent copy.
  2. Forgetting the base case: Stop when index == A.size().
  3. Forgetting to backtrack: Remove the last element before exploring the exclude branch.
  4. Not advancing the index: Every recursive call must use index + 1 to process the next element.

Likely interviewer follow-ups

Q: Why are there \(2^N\) subsets?

Every element has two independent choices: include or exclude.

Q: Can this be solved iteratively?

Yes. Start with [[]]; for every element, add it to copies of all existing subsets.

Q: What if the array contains duplicates?

Sort the array and skip duplicate values at the same recursion depth to prevent duplicate subsets.

Q: Why is backtracking useful?

It lets us explore a choice, undo it, and explore another choice without creating a separate working list for every recursive call.

9. Final Recommendation

For interview preparation, focus on the include/exclude backtracking approach. It is easy to explain and applies to many problems involving subsets, combinations, and decision trees.

  • Recommended approach: Backtracking
  • Time complexity: \(O(N \times 2^N)\)
  • Auxiliary space: \(O(N)\), excluding the output
  • Output space: \(O(N \times 2^N)\)
Remember: At every index, include the element, explore recursively, undo the choice, and then explore without the element. When you reach the end of the array, save the subset.
