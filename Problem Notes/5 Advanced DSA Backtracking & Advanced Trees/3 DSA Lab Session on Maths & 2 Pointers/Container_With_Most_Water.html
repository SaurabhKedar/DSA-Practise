Java Algorithm Guide

Container With Most Water

A classic two-pointer problem. Since \(N\) can be as large as \(10^5\), the two-pointer solution reduces the running time to \(O(N)\).

Recommended pattern: Start with the widest pair and move inward from the shorter boundary.

1. Problem Understanding

You are given an array A, where each element represents the height of a vertical line. Choose two lines that, together with the x-axis, form a container that holds as much water as possible.

For lines at indices i and j, the area is:

\[\text{Area}=\min(A[i],A[j])\times(j-i)\]
  • A[i] and A[j] are the heights of the two lines.
  • j - i is the width between them.
  • The shorter line determines the maximum water height.

Example: A = [1, 5, 4, 3]

Choose heights 5 and 3, at zero-based indices 1 and 3.

  • Width: \(3-1=2\)
  • Height: \(\min(5,3)=3\)
  • Area: \(2\times3=\mathbf{6}\)

Output: 6

For A = [1], there is only one line, so no container can be formed. The output is 0.

2. Brute Force Approach

Intuition

Try every possible pair of lines, calculate its area, and keep track of the maximum.

Java code

public class Solution {
    public int maxArea(int[] A) {
        int n = A.length;
        int maxArea = 0;

        // Try every possible pair of lines.
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // The shorter line limits the water height.
                int height = Math.min(A[i], A[j]);

                // Distance between the two lines.
                int width = j - i;

                int area = height * width;

                // Keep the largest area found so far.
                maxArea = Math.max(maxArea, area);
            }
        }

        return maxArea;
    }
}

Complexity

  • Time: \(O(N^2)\), because every pair is examined.
  • Auxiliary space: \(O(1)\), because only a few variables are used.

For \(N=10^5\), there can be almost five billion pairs, making brute force too slow.

3. Optimized Approach — Two Pointers

Intuition

Start with the two lines that are farthest apart:

  • left = 0: the first line.
  • right = n - 1: the last line.

Calculate the area and update the maximum. Then move the pointer at the shorter line. The shorter line limits the water height. Moving the taller line inward would reduce the width without allowing a greater height than the current shorter line. Moving the shorter line gives a chance to find a taller boundary.

Two-pointer algorithm

  1. Initialize left = 0, right = n - 1, and maxArea = 0.
  2. While left < right, calculate the area using the shorter height and the width.
  3. Update maxArea if the current area is larger.
  4. If A[left] < A[right], move left forward. Otherwise, move right backward.
  5. Return maxArea when the pointers meet.

Optimized Java code

public class Solution {
    public int maxArea(int[] A) {
        int left = 0;
        int right = A.length - 1;
        int maxArea = 0;

        // Continue while two different lines remain.
        while (left < right) {
            // Water height is limited by the shorter line.
            int height = Math.min(A[left], A[right]);

            // Width is the distance between the lines.
            int width = right - left;

            // Calculate this container's area.
            int area = height * width;

            // Update the best area found so far.
            maxArea = Math.max(maxArea, area);

            // Move the pointer at the shorter boundary.
            if (A[left] < A[right]) {
                left++;
            } else {
                right--;
            }
        }

        return maxArea;
    }
}

This preserves the required method signature for the platform.

4. Dry Run of the Optimized Solution

Input: A = [1, 5, 4, 3]. Initially, left = 0, right = 3, and maxArea = 0.

11333Move left
25326Move right
35414Move right

At the end, left = 1 and right = 1. Since left < right is false, the loop stops.

Final answer: 6.

When the first area is 3, we discard the line of height 1. Any container using that line has a maximum height of 1, and a smaller width cannot improve upon its best possible area.

Why Does This Optimization Work?

Suppose the current boundaries have heights \(h_L\) and \(h_R\), and the width is \(w\).

If \(h_L \le h_R\), the current area is \(h_L \times w\). Moving the right pointer inward keeps the left height as a limiting boundary while reducing the width. Therefore, moving the right pointer cannot produce a better area with the current left boundary.

We can safely discard that shorter boundary and move left forward. The same reasoning applies when the right boundary is shorter. This lets the algorithm skip many pairs without missing the maximum area.

5. Complexity Analysis

Approach Time complexity Auxiliary space
Brute force\(O(N^2)\)\(O(1)\)
Two pointers\(O(N)\)\(O(1)\)

Optimized time: Each iteration moves either left or right inward. Each pointer moves at most \(N-1\) positions, so the total work is linear.

Space: Only three variables are used, regardless of input size.

8. Interview Preparation Notes

Pattern to remember: Two pointers start at opposite ends, and we move the pointer at the shorter height.

Common interview questions

Q1. Why not move the pointer at the taller line?
The shorter line already limits the height. Moving the taller line inward reduces width without improving the limiting height for that boundary.
Q2. What if both heights are equal?
Move either pointer. The code above moves right when the heights are equal. The same correctness argument applies.
Q3. Can sorting optimize this problem?
No. Sorting changes the original index distances, which determine the container width. The two-pointer method works directly on the original array.
Q4. Why is this not a sliding-window problem?
There is no fixed or variable window condition to maintain. Instead, we eliminate one boundary at each step using a mathematical property of the area formula.

9. Final Recommendation

Use the two-pointer approach in interviews because it reduces the running time from \(O(N^2)\) to \(O(N)\) without requiring extra data structures.

  • Time complexity: \(O(N)\)
  • Auxiliary space: \(O(1)\)
Start with the widest container. Calculate its area, then move the shorter boundary inward because only that boundary has a chance to improve the limiting height.
