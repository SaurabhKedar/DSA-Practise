Java Algorithm Guide

Identical Binary Trees

This fundamental binary-tree problem uses recursion and tree traversal. The recommended interview approach is recursive DFS: compare the trees node by node, checking both values and structure at the same time.

Pattern to remember: Two trees are identical when corresponding nodes match in value and their corresponding left and right subtrees are identical.

1. Problem Understanding

We are given the roots of two binary trees, A and B, and need to determine whether they are exactly identical.

Two trees are identical when:

  1. They have the same structure.
  2. Corresponding nodes have the same values.
  3. Their left subtrees are identical.
  4. Their right subtrees are identical.

Return 1 when the trees are identical and 0 otherwise.

Example 1 — identical trees

Tree A:       Tree B:

    1             1
   / \           / \
  2   3         2   3

Output: 1. Both trees have the same structure and corresponding values.

Example 2 — different values

Tree A:       Tree B:

    1             1
   / \           / \
  2   3         3   3

Output: 0. The left child values differ: 2 and 3.

2. Brute Force Approach — Store Traversals

Traverse both trees in preorder and store the results, including a marker for every null child. Null markers are necessary because preorder values alone cannot distinguish every tree shape.

Why include null markers?

Tree 1:       Tree 2:

    1             1
   /               \
  2                 2

Both have preorder values [1, 2], but their structures differ. A special null marker preserves the shape.

Java code — preorder serialization

import java.util.ArrayList;
import java.util.List;

public class Solution {

    public int isSameTree(TreeNode A, TreeNode B) {
        List<Integer> listA = new ArrayList<>();
        List<Integer> listB = new ArrayList<>();

        // Serialize both trees in preorder, preserving null children.
        preorder(A, listA);
        preorder(B, listB);

        // Equal serializations imply equal values and structure.
        return listA.equals(listB) ? 1 : 0;
    }

    private void preorder(TreeNode root, List<Integer> list) {
        if (root == null) {
            list.add(null);
            return;
        }

        list.add(root.val);
        preorder(root.left, list);
        preorder(root.right, list);
    }
}

Dry run

The lists are identical, so the result is 1.

Complexity and limitation

  • Time: \(O(N + M)\), where \(N\) and \(M\) are the numbers of nodes in the two trees.
  • Space: \(O(N + M)\) to store both traversals, including null markers.
  • This uses extra memory. We can compare the trees directly without storing the traversals.

3. Optimized Approach — Recursive DFS

Compare corresponding nodes simultaneously instead of traversing and storing each tree separately.

Intuition

Tree A:       Tree B:

    1             1
   / \           / \
  2   3         2   3
  1. Compare the roots.
  2. Compare the left child of A with the left child of B.
  3. Compare the right child of A with the right child of B.
  4. Continue recursively for each corresponding pair.

Three important conditions

Both nodes are null

if (A == null && B == null)
    return 1;

The corresponding branches match at this position.

Only one node is null

if (A == null || B == null)
    return 0;

One tree has a node where the other does not, so their structures differ.

Both nodes exist

if (A.val != B.val)
    return 0;

Different values make the trees non-identical. Otherwise, compare both subtrees.

Algorithm

  1. Start with the roots of both trees.
  2. If both are null, return 1.
  3. If only one is null, return 0.
  4. If their values differ, return 0.
  5. Recursively compare their left children and right children.
  6. Return 1 only when both subtree comparisons return 1.

Java code — interview solution

public class Solution {

    public int isSameTree(TreeNode A, TreeNode B) {
        // Case 1: Both nodes are null, so these branches match.
        if (A == null && B == null) {
            return 1;
        }

        // Case 2: Only one node is null, so the structures differ.
        if (A == null || B == null) {
            return 0;
        }

        // Case 3: Both nodes exist, but their values must match.
        if (A.val != B.val) {
            return 0;
        }

        // Compare corresponding left and right subtrees.
        int left = isSameTree(A.left, B.left);
        int right = isSameTree(A.right, B.right);

        // Both subtree comparisons must succeed.
        return (left == 1 && right == 1) ? 1 : 0;
    }
}

Understanding the return statement

return (left == 1 && right == 1) ? 1 : 0;
  • If both left and right subtrees are identical, return 1.
  • Otherwise, return 0.
  • We use && because both sides must match.

One could also use bitwise & on the integer-returning recursive calls; that evaluates both calls. The explicit version using && on boolean conditions is easier to understand.

For the second example, the roots match (1 == 1), but the left children do not (2 != 3). The algorithm immediately returns 0; it does not need to check the remaining subtrees.

5. Complexity Analysis

ApproachTime complexityAuxiliary space
Brute force (serialization)\(O(N + M)\)\(O(N + M)\)
Recursive DFS\(O(\min(N, M))\) for an early mismatch; \(O(N + M)\) worst case\(O(H)\) recursion stack
Iterative DFS\(O(N + M)\) worst caseStack of node pairs; \(O(N + M)\) is a loose worst-case bound
  • N and M are the numbers of nodes in Tree A and Tree B.
  • H is the maximum recursion depth.
  • When both trees are identical, every corresponding node is visited. If both have \(N\) nodes, the time is \(O(N)\).
  • Recursive space is \(O(\log N)\) for a balanced tree and \(O(N)\) for a skewed tree.
Constraint consideration: The problem permits up to \(10^5\) nodes. A highly skewed tree can cause Java recursion stack overflow, so an iterative DFS is useful when robustness against deep trees matters.

6. Iterative Optimized Approach — Using a Stack

Avoid recursion by maintaining pairs of corresponding nodes in an explicit stack.

For each pair

  1. If both nodes are null, continue.
  2. If only one is null, return 0.
  3. If their values differ, return 0.
  4. Push their left children as a pair, and their right children as a pair.

Java code

import java.util.Stack;

public class Solution {

    static class NodePair {
        TreeNode first;
        TreeNode second;

        NodePair(TreeNode first, TreeNode second) {
            this.first = first;
            this.second = second;
        }
    }

    public int isSameTree(TreeNode A, TreeNode B) {
        Stack<NodePair> stack = new Stack<>();

        // Begin by comparing the two roots.
        stack.push(new NodePair(A, B));

        while (!stack.isEmpty()) {
            NodePair pair = stack.pop();
            TreeNode first = pair.first;
            TreeNode second = pair.second;

            // Matching null branches need no further processing.
            if (first == null && second == null) {
                continue;
            }

            // A node on only one side means the structures differ.
            if (first == null || second == null) {
                return 0;
            }

            // Corresponding values must be equal.
            if (first.val != second.val) {
                return 0;
            }

            // Add corresponding children so both sides are checked.
            stack.push(new NodePair(first.left, second.left));
            stack.push(new NodePair(first.right, second.right));
        }

        // Every corresponding pair matched.
        return 1;
    }
}

Time

\(O(N + M)\) in the worst case.

Auxiliary space

The stack stores pending node pairs; the iterative approach avoids recursion stack overflow.

9. Interview Preparation Notes

Key concept to remember

Recursive DFS compares two trees simultaneously. Remember these three conditions:

// Both null means this branch matches.
if (A == null && B == null)
    return 1;

// One null means the structures differ.
if (A == null || B == null)
    return 0;

// Different values mean the trees differ.
if (A.val != B.val)
    return 0;

If none of these conditions fails, compare the left and right subtrees.

Common interview mistakes

  1. Checking only node values: trees can have the same values but different structures.
  2. Ignoring null conditions: null checks are essential to verify structure.
  3. Using OR instead of AND: both left and right subtrees must match.
  4. Comparing left with right: identical trees compare left with left and right with right.
  5. Ignoring recursion depth: a skewed tree with 100,000 nodes can cause stack overflow.

Likely interviewer follow-up questions

Can we solve this using BFS?

Yes. Use a queue containing pairs of corresponding nodes. Apply the same three checks and enqueue the corresponding children.

Why do we need to check null nodes?

Null nodes help verify structural equality. Without them, differently shaped trees might incorrectly appear identical.

What is the difference between identical and symmetric trees?

  • Identical: compare left with left and right with right.
  • Symmetric: compare left with right and right with left.

Can we solve this without recursion?

Yes. Use an explicit stack or queue to compare corresponding node pairs iteratively.

10. Final Recommendation

For interviews, understand and implement the recursive DFS solution first. It is the simplest and most readable approach. Since the constraint allows up to 100,000 nodes, also remember the iterative stack solution.
