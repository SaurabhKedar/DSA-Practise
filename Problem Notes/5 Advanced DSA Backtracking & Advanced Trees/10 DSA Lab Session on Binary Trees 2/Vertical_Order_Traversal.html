Java Algorithm Guide

Vertical Order Traversal

Group the nodes of a binary tree by their vertical columns, from left to right. Breadth-First Search (BFS) with horizontal distance processes nodes top to bottom within each column.

Pattern to remember: Assign each node a horizontal distance, traverse level by level, and append each value to its column.

1. Problem Understanding

We need to group the nodes of a binary tree according to their vertical columns, from left to right.

Assign each node a horizontal distance (HD):

  • The root has HD 0.
  • A left child has HD parent HD - 1.
  • A right child has HD parent HD + 1.

Nodes with the same horizontal distance belong to the same column.

Example columns

The columns from left to right are:

[[2], [3], [6, 5], [7], [9]]

Nodes 6 and 5 share a column. Since 6 is at a smaller depth, it appears first.

2. Brute Force Approach

Traverse the entire tree and store each node together with its horizontal distance and depth.

  1. Record (horizontal distance, depth, value) for every node.
  2. Sort all records by horizontal distance.
  3. For equal horizontal distances, sort by depth.
  4. Group the values by horizontal distance.

Sorting places columns from left to right and nodes from top to bottom within each column. Sorting all nodes takes \(O(N\log N)\) time and requires storing the traversal records.

Brute-force Java code

import java.util.*;

public class Solution {

    // Stores each node's position and value.
    static class NodeInfo {
        int hd;
        int depth;
        int value;

        NodeInfo(int hd, int depth, int value) {
            this.hd = hd;
            this.depth = depth;
            this.value = value;
        }
    }

    public ArrayList<ArrayList<Integer>> verticalOrderTraversal(TreeNode A) {
        ArrayList<ArrayList<Integer>> result = new ArrayList<>();

        if (A == null) {
            return result;
        }

        ArrayList<NodeInfo> nodes = new ArrayList<>();

        // Collect all nodes with their horizontal distance and depth.
        collect(A, 0, 0, nodes);

        // Sort by column first, then by depth.
        nodes.sort((a, b) -> {
            if (a.hd != b.hd) {
                return Integer.compare(a.hd, b.hd);
            }
            return Integer.compare(a.depth, b.depth);
        });

        int previousHD = Integer.MIN_VALUE;

        for (NodeInfo node : nodes) {
            // Start a new column when horizontal distance changes.
            if (node.hd != previousHD) {
                result.add(new ArrayList<>());
                previousHD = node.hd;
            }

            result.get(result.size() - 1).add(node.value);
        }

        return result;
    }

    private void collect(TreeNode node, int hd, int depth,
                         ArrayList<NodeInfo> nodes) {
        if (node == null) {
            return;
        }

        nodes.add(new NodeInfo(hd, depth, node.val));

        collect(node.left, hd - 1, depth + 1, nodes);
        collect(node.right, hd + 1, depth + 1, nodes);
    }
}

Time complexity

\(O(N\log N)\), because all \(N\) node records are sorted.

Auxiliary space

\(O(N)\) for node records and \(O(H)\) for recursion, where \(H\) is the tree height.

If two nodes have the same horizontal distance and depth, this sorting approach does not explicitly define their order. The BFS solution below preserves their natural left-to-right traversal order.

3. Optimized Approach — BFS + HashMap

Intuition

BFS visits nodes level by level: the root first, then its children, then the next level. Store each node in the list for its horizontal distance. A HashMap stores column values, while minHD and maxHD track the leftmost and rightmost columns.

Algorithm

  1. If the root is null, return an empty result.
  2. Insert the root into a queue with horizontal distance 0.
  3. Remove nodes one at a time and append each value to its column.
  4. Give a left child HD hd - 1 and a right child HD hd + 1.
  5. Update the minimum and maximum horizontal distances.
  6. After BFS, collect columns in increasing horizontal-distance order.

Interview-ready Java code

import java.util.*;

public class Solution {

    // Stores a tree node along with its horizontal distance.
    static class Pair {
        TreeNode node;
        int hd;

        Pair(TreeNode node, int hd) {
            this.node = node;
            this.hd = hd;
        }
    }

    public ArrayList<ArrayList<Integer>> verticalOrderTraversal(TreeNode A) {

        ArrayList<ArrayList<Integer>> result = new ArrayList<>();

        // Handle an empty tree.
        if (A == null) {
            return result;
        }

        // Maps each horizontal distance to its column values.
        HashMap<Integer, ArrayList<Integer>> columns = new HashMap<>();

        // BFS queue stores both the node and its horizontal distance.
        Queue<Pair> queue = new LinkedList<>();
        queue.offer(new Pair(A, 0));

        int minHD = 0;
        int maxHD = 0;

        while (!queue.isEmpty()) {

            Pair current = queue.poll();
            TreeNode node = current.node;
            int hd = current.hd;

            // Create a column if this horizontal distance is new.
            columns.putIfAbsent(hd, new ArrayList<>());

            // BFS guarantees shallower nodes are processed first.
            columns.get(hd).add(node.val);

            // Track the leftmost and rightmost columns.
            minHD = Math.min(minHD, hd);
            maxHD = Math.max(maxHD, hd);

            // Left child belongs to the previous column.
            if (node.left != null) {
                queue.offer(new Pair(node.left, hd - 1));
            }

            // Right child belongs to the next column.
            if (node.right != null) {
                queue.offer(new Pair(node.right, hd + 1));
            }
        }

        // Build the answer from leftmost column to rightmost.
        for (int hd = minHD; hd <= maxHD; hd++) {
            result.add(columns.get(hd));
        }

        return result;
    }
}

Why Does BFS Solve the Depth-Order Requirement?

Consider this tree:

       6
      / \
     3   7
    / \
   2   5

BFS processes nodes in this order: 6 → 3 → 7 → 2 → 5. Node 6 is at depth 0 with HD 0; node 5 is at depth 2 with HD 0. Therefore, column 0 receives 6 before 5.

BFS naturally preserves the required depth order without sorting individual nodes.
