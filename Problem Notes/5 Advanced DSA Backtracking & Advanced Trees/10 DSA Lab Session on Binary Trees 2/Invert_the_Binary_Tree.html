Invert the Binary Tree

This classic binary-tree and recursion problem can be solved by swapping the left and right child of every node. Recursive DFS is easy to understand; iterative BFS avoids recursion depth limits on highly skewed trees.

Pattern to remember: Visit every node, swap its left and right children, and continue until all nodes have been processed.

1. Problem Understanding

We are given the root of a binary tree. Invert it by swapping the left and right child of every node, then return the root of the inverted tree.

The input is a binary tree with at least one node. Each node has a value, a left pointer, and a right pointer.

Important points:

  1. Swap child pointers, not node values.
  2. Invert every node in the tree.
  3. The original root remains the root.
  4. Modify the tree structure directly.

Original tree

       1
      / \
     2   3
    / \ / \
   4  5 6  7

After inversion

       1
      / \
     3   2
    / \ / \
   7  6 5  4
  • At node 1, swap 2 and 3.
  • At node 2, swap 4 and 5.
  • At node 3, swap 6 and 7.

Apply the same operation at every node.

2. Recursive DFS Approach

There is no meaningfully inferior brute-force algorithm needed here. The simplest approach is recursion, which is also the recommended solution for understanding the operation.

At every node:

  1. Store the current left child temporarily.
  2. Assign the right child to the left pointer.
  3. Assign the stored left child to the right pointer.
  4. Recursively invert the left and right subtrees.
  5. Return the current node.

Java solution

public class Solution {
    public TreeNode invertTree(TreeNode A) {

        // A null node has no children to swap.
        if (A == null) {
            return null;
        }

        // Swap the left and right child pointers.
        TreeNode temp = A.left;
        A.left = A.right;
        A.right = temp;

        // Invert both subtrees after swapping them.
        invertTree(A.left);
        invertTree(A.right);

        // The current node remains the root of this inverted subtree.
        return A;
    }
}

Recursive complexity

  • Time: O(N), because every node is visited once and swapping pointers takes constant time.
  • Auxiliary space: O(H), where H is the tree height, due to the recursive call stack.
  • Balanced tree: O(log N) call-stack space.
  • Skewed tree: O(N) call-stack space.
Limitation: A highly skewed tree with 100,000 nodes may cause a Java StackOverflowError because of the recursive call depth.

3. Optimized Approach — Iterative BFS

A queue can replace the recursion stack. This level-order traversal is particularly useful when the tree may contain up to 100,000 nodes.

Visit each node, swap its children, and add each non-null child to the queue.

  1. If the root is null, return null.
  2. Create a queue and insert the root.
  3. While the queue is not empty, remove the front node and swap its children.
  4. Add the node's new left and right children to the queue when they are non-null.
  5. Return the original root.

Java solution — interview-ready

import java.util.LinkedList;
import java.util.Queue;

public class Solution {
    public TreeNode invertTree(TreeNode A) {

        // An empty tree needs no changes.
        if (A == null) {
            return null;
        }

        // Use a queue to visit nodes level by level.
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(A);

        while (!queue.isEmpty()) {
            // Remove the next node to process.
            TreeNode current = queue.poll();

            // Swap this node's left and right child pointers.
            TreeNode temp = current.left;
            current.left = current.right;
            current.right = temp;

            // Queue the swapped children so their subtrees are processed.
            if (current.left != null) {
                queue.offer(current.left);
            }
            if (current.right != null) {
                queue.offer(current.right);
            }
        }

        // Return the original root, now the root of the inverted tree.
        return A;
    }
}

Why this works

After swapping a node's children, both non-null children are enqueued. Thus every node is eventually processed exactly once, and every node's children are swapped.

Iterative complexity

  • Time: O(N), because every node is inserted into and removed from the queue once.
  • Auxiliary space: O(W), where W is the maximum width of the tree.
  • Balanced tree: queue space can be O(N) in the worst case.
  • Skewed tree: queue space is O(1), since at most one node is queued at a time.

7. Interview Preparation Notes

Key concepts to remember

  1. DFS (Depth First Search): Visit nodes recursively.
  2. BFS (Breadth First Search): Visit nodes level by level using a queue.
  3. Tree manipulation: Modify pointers instead of creating a new tree.
  4. Recursion: Solve the same smaller problem on the left and right subtrees.

Common interview mistakes

  • Swapping node values instead of child pointers.
  • Forgetting to process both subtrees.
  • Forgetting the null base case.
  • Returning the wrong root.
  • Ignoring recursion stack limitations for large trees.

Likely interviewer follow-up questions

Q1. Can we invert a binary tree without recursion?
Yes. Use a queue (BFS) or a stack (iterative DFS).
Q2. Do we need to create a new binary tree?
No. We modify the existing tree by swapping its child pointers.
Q3. What is the difference between DFS and BFS here?
DFS explores one subtree deeply before another. BFS processes nodes level by level. Both take O(N) time.
Q4. Can we invert a BST using the same algorithm?
Yes. It will invert the tree structure, but the resulting tree will generally no longer satisfy the original BST ordering property.

8. Final Recommendation

Recommended for a tree that may contain up to 100,000 nodes: Iterative BFS.

For interview preparation, remember both implementations:

  • Recursive DFS: easiest to understand and explain.
  • Iterative BFS: safer for a potentially deep tree with 100,000 nodes.

Final complexity for BFS:

  • Time: O(N).
  • Auxiliary space: O(W).
