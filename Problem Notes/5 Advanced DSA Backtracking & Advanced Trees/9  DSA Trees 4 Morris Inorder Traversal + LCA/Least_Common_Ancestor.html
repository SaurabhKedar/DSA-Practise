Binary Trees · Depth-First Search

Least Common Ancestor (LCA)

Find the lowest node in an unordered binary tree that is an ancestor of both target values.

Recommended approach: Use recursive DFS to find both targets and propagate their LCA candidate in one traversal. Return -1 if either target is missing.

1. Problem Understanding

You are given an unordered binary tree and two values, B and C. Return the value of their Lowest Common Ancestor (LCA).

The LCA is the deepest node in the tree that is an ancestor of both target nodes. A node is considered an ancestor of itself.

For example, consider this tree, where 1 is the root and 4 and 5 are children of node 2:

        1
       / \
      2   3
     / \
    4   5
  • If B = 4 and C = 5, the LCA is 2.
  • If B = 2 and C = 3, the LCA is 1.
  • If one target node is an ancestor of the other, that ancestor itself is the LCA.

Important: If either B or C does not exist in the tree, return -1. The standard recursive LCA algorithm alone can return a node even when one target is missing.

2. Brute Force Approach

Idea: Find both paths from the root

Find the path from the root to B and the path from the root to C. Compare the paths from the beginning; their last common node is the LCA.

For example:

  • Path to B = 4: [1, 2, 4]
  • Path to C = 5: [1, 2, 5]

The common prefix is [1, 2], so the answer is 2.

Steps

  1. Use DFS to find the path from the root to B.
  2. Use DFS to find the path from the root to C.
  3. If either path is missing, return -1.
  4. Compare the paths and return their last common node.

Brute-force Java solution

import java.util.*;

public class Solution {

    // Finds the path from root to the target value.
    private boolean findPath(TreeNode root, int target,
                             ArrayList<Integer> path) {
        if (root == null) {
            return false;
        }

        // Include the current node in the path.
        path.add(root.val);

        if (root.val == target) {
            return true;
        }

        // Search the left or right subtree.
        if (findPath(root.left, target, path) ||
            findPath(root.right, target, path)) {
            return true;
        }

        // This node is not part of the target path.
        path.remove(path.size() - 1);
        return false;
    }

    public int lca(TreeNode A, int B, int C) {
        ArrayList<Integer> pathB = new ArrayList<>();
        ArrayList<Integer> pathC = new ArrayList<>();

        // Both targets must exist in the tree.
        if (!findPath(A, B, pathB) ||
            !findPath(A, C, pathC)) {
            return -1;
        }

        int i = 0;
        int lca = -1;

        // Find the last common node in both paths.
        while (i < pathB.size() && i < pathC.size()
                && pathB.get(i).equals(pathC.get(i))) {
            lca = pathB.get(i);
            i++;
        }

        return lca;
    }
}

Complexity analysis

  • Time: \(O(N)\). Each DFS can visit up to \(N\) nodes, and comparing the paths takes at most \(O(N)\).
  • Auxiliary space: \(O(H)\) for the two paths and recursion stack, where \(H\) is the tree height. In a skewed tree, this becomes \(O(N)\).

Limitation: This approach stores two paths and traverses the tree multiple times. A single traversal can find the LCA and verify target existence.

3. Optimized Approach — Recursive DFS

Instead of building paths, let each recursive call report three things about its subtree:

  • The potential LCA found in that subtree.
  • Whether B exists in that subtree.
  • Whether C exists in that subtree.

At each node

  1. If the current node is null, return an empty result.
  2. Recursively process the left and right subtrees.
  3. Check whether the current node matches B or C.
  4. If the current node is one of the targets, it may be the LCA.
  5. If one target is found on the left and the other on the right, the current node is their LCA.
  6. Otherwise, pass the LCA candidate from either subtree upward.
  7. At the root, return the LCA only if both targets were found; otherwise, return -1.

Optimized Java solution

This solution preserves the required public int lca(TreeNode A, int B, int C) signature.

/**
 * Definition for binary tree
 * class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode(int x) {
 *         val = x;
 *         left = null;
 *         right = null;
 *     }
 * }
 */

public class Solution {

    // Stores the result of processing a subtree.
    private static class Result {
        TreeNode lca;
        boolean foundB;
        boolean foundC;

        Result(TreeNode lca, boolean foundB, boolean foundC) {
            this.lca = lca;
            this.foundB = foundB;
            this.foundC = foundC;
        }
    }

    private Result findLCA(TreeNode root, int B, int C) {
        // An empty subtree contains neither target.
        if (root == null) {
            return new Result(null, false, false);
        }

        // Process both subtrees.
        Result left = findLCA(root.left, B, C);
        Result right = findLCA(root.right, B, C);

        // Check whether the current node matches either target.
        boolean isB = (root.val == B);
        boolean isC = (root.val == C);

        // Combine target-existence information.
        boolean foundB = isB || left.foundB || right.foundB;
        boolean foundC = isC || left.foundC || right.foundC;

        TreeNode lca = null;

        // The current node is the LCA if it is a target
        // and the other target exists below it.
        if (isB || isC) {
            lca = root;
        }

        // Targets found in separate subtrees have this node
        // as their lowest common ancestor.
        else if (left.lca != null && right.lca != null) {
            lca = root;
        }

        // Otherwise, pass the candidate from the non-empty side.
        else if (left.lca != null) {
            lca = left.lca;
        } else if (right.lca != null) {
            lca = right.lca;
        }

        return new Result(lca, foundB, foundC);
    }

    public int lca(TreeNode A, int B, int C) {
        Result result = findLCA(A, B, C);

        // Return -1 if either target is missing.
        if (!result.foundB || !result.foundC) {
            return -1;
        }

        return result.lca.val;
    }
}

This approach assumes node values are unique, as is customary for this version of the problem. It also handles B == C by treating the matching node as both targets.

What if a target is missing?

Suppose B = 4 and C = 10, but node 10 does not exist. The recursive search finds 4, but foundC remains false. Therefore, the method returns -1 instead of incorrectly returning 4 or another ancestor.

5. Complexity Comparison

Let \(N\) be the number of nodes and \(H\) be the height of the tree.

Approach Time complexity Auxiliary space Main idea
Brute force\(O(N)\)\(O(H)\)Find both paths and compare
Optimized DFS\(O(N)\)\(O(H)\)Find the LCA and verify both targets in one traversal

The optimized solution reduces the number of tree traversals and avoids storing complete root-to-node paths. Both approaches have the same worst-case Big-O time complexity.

Recursion-depth note: Because the constraints allow up to \(10^5\) nodes, a highly skewed tree could cause a Java StackOverflowError with recursive DFS. If the platform includes such extreme cases, an iterative solution is safer.

8. Interview Preparation Notes

Pattern to remember: Binary tree DFS with recursive result propagation.

Common mistakes

  • Returning an LCA candidate without checking that both targets exist.
  • Assuming the tree is a BST and using value comparisons to choose a subtree.
  • Forgetting that one target can itself be the LCA.
  • Ignoring recursion depth for a tree with up to \(10^5\) nodes.

Likely interview follow-ups

  1. How does the solution change for a BST? Use the ordering property to move left or right until the two values split across subtrees or one equals the current node.
  2. What if each node has a parent pointer? Find the ancestors of one node, then walk up from the other until an ancestor matches.
  3. What if one target might not exist? Track whether both targets were found, as this problem requires.
  4. Can recursion be avoided? Yes. Find both paths iteratively using a stack or parent map, then compare the paths.

9. Final Recommendation

Implement the optimized recursive DFS for this problem because it directly captures the LCA pattern and verifies that both target values exist.

  • Time: \(O(N)\)
  • Auxiliary space: \(O(H)\), worst case \(O(N)\)

Remember: If the two targets are found in different subtrees, the current node is their LCA. If only one subtree has an LCA candidate, pass that candidate upward. Finally, return -1 if either target is missing.
