Preorder Traversal of a Binary Tree

Preorder traversal visits the current node first, then its left subtree, and finally its right subtree. The iterative depth-first search (DFS) version uses a stack and avoids depending on Java's recursion depth.

Pattern to remember: Root → Left → Right

1. Problem Understanding

Given the root node A of a binary tree, return an ArrayList<Integer> containing the values of all nodes in preorder traversal.

For each node, follow this order:

  1. Visit the current node and add its value.
  2. Traverse the left subtree.
  3. Traverse the right subtree.

Example tree

        1
       / \
      2   3
         /
        4

Visit the root, then the left subtree, then the right subtree. The preorder traversal is [1, 2, 3, 4].

2. Basic Approach — Recursive DFS

There is no need to search for every node separately. Recursion directly follows the preorder definition and visits each node once. This approach is already optimal in time complexity.

Algorithm

  1. Create an empty ArrayList<Integer>.
  2. If the current node is null, return.
  3. Add the current node's value to the list.
  4. Recursively traverse the left subtree, then the right subtree.
  5. Return the list.

Java solution — Recursive

import java.util.ArrayList;

/**
 * Definition for binary tree
 * class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode(int x) {
 *         val = x;
 *         left = null;
 *         right = null;
 *     }
 * }
 */

public class Solution {
    public ArrayList<Integer> preorderTraversal(TreeNode A) {
        ArrayList<Integer> result = new ArrayList<>();

        // Start preorder traversal at the root.
        preorder(A, result);

        return result;
    }

    private void preorder(TreeNode node, ArrayList<Integer> result) {
        // Base case: there is no node to visit.
        if (node == null) {
            return;
        }

        // Visit the root before either subtree.
        result.add(node.val);

        // Continue in preorder: left subtree, then right subtree.
        preorder(node.left, result);
        preorder(node.right, result);
    }
}

Recursive dry run

Use the example tree shown above.

Step Action Result
1Visit root 1.[1]
2Visit left child 2.[1, 2]
3The children of 2 are null; return to the root.[1, 2]
4Visit right child 3.[1, 2, 3]
5Visit left child 4 of 3.[1, 2, 3, 4]
6The remaining children are null; traversal ends.[1, 2, 3, 4]

Final output: [1, 2, 3, 4]

3. Optimized Approach — Iterative DFS Using a Stack

Recursive traversal is time-optimal, but the tree may contain up to \(10^5\) nodes. A highly skewed tree can make recursion very deep and potentially cause a StackOverflowError in Java. An iterative traversal uses an explicit stack instead.

Intuition

A stack is Last In, First Out (LIFO). Push the root, repeatedly pop and visit a node, then push its right child before its left child. Since the left child is pushed last, it is on top and is processed first.

Java solution — Iterative

import java.util.ArrayList;
import java.util.Stack;

public class Solution {
    public ArrayList<Integer> preorderTraversal(TreeNode A) {
        ArrayList<Integer> result = new ArrayList<>();

        // An empty tree has no nodes to traverse.
        if (A == null) {
            return result;
        }

        Stack<TreeNode> stack = new Stack<>();
        stack.push(A);

        while (!stack.isEmpty()) {
            // Pop and visit the next node in preorder.
            TreeNode node = stack.pop();
            result.add(node.val);

            // Push right first so the left child is processed first.
            if (node.right != null) {
                stack.push(node.right);
            }

            if (node.left != null) {
                stack.push(node.left);
            }
        }

        return result;
    }
}

Both solutions preserve the required method signature. For a tree with up to \(10^5\) nodes, the iterative approach avoids dependence on Java's recursion depth.

5. Complexity Analysis

Let \(n\) be the number of nodes and \(h\) be the height of the tree.

Approach Time complexity Auxiliary space
Recursive DFS\(O(n)\)\(O(h)\) recursion stack
Iterative DFS\(O(n)\)\(O(n)\) stack in the worst case

Why is the time \(O(n)\)?

Every node is visited exactly once, and each visit takes constant time.

Why does space complexity differ?

Recursive DFS uses a call stack whose depth depends on the tree height: \(O(\log n)\) for a balanced tree and \(O(n)\) for a skewed tree. Iterative DFS stores pending nodes in an explicit stack, requiring up to \(O(n)\) auxiliary space in the worst case. Both approaches also use \(O(n)\) space for the returned list, separate from auxiliary space.

8. Interview Preparation Notes

Key concept to remember

Preorder is a Depth-First Search (DFS) traversal.

  • Preorder: Root → Left → Right
  • Inorder: Left → Root → Right
  • Postorder: Left → Right → Root

Common mistakes

  1. Visiting the left or right subtree before adding the root value.
  2. Pushing the left child before the right child in the iterative solution, which reverses the intended processing order.
  3. Forgetting the null base case in recursion.
  4. Assuming recursive space is always \(O(\log n)\); it can be \(O(n)\) for a skewed tree.

Likely interviewer follow-up questions

Q1. Why do we push the right child before the left child?
A stack processes the last inserted element first. Pushing right before left ensures the left child is processed first.
Q2. Can preorder traversal be implemented without recursion?
Yes. Use an explicit stack, as shown in the iterative solution.
Q3. What is the difference between DFS and BFS?
DFS explores deeper along a branch before returning. BFS explores nodes level by level using a queue.
Q4. Is \(O(n)\) time optimal?
Yes. Every node must be visited to return all node values, giving a lower bound of \(\Omega(n)\).

9. Final Recommendation

For interview preparation, understand the recursive solution first because it expresses the preorder definition directly. Then implement the iterative version when you want to avoid recursion-depth issues.

  • Recommended for large or potentially skewed trees: iterative DFS using a stack.
  • Time complexity: \(O(n)\).
  • Auxiliary space: \(O(n)\) worst case for the iterative approach.
One-line memory trick: Preorder means visit the Parent first, then Left, then Right — Root → Left → Right.
