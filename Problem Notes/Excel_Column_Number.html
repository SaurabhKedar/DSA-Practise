Excel Column Number — Java Solution

Convert an Excel column title such as AB into its corresponding number. The key idea is to evaluate the letters as a base-26 positional number, with letter values from 1 to 26.

Core idea: For each letter from left to right, multiply the accumulated result by 26, then add that letter's value.

1. Problem Understanding

In Excel, columns are named using letters instead of numbers. Given a string A representing an Excel column title, return its corresponding column number.

Column title Number Column title Number
A1AA27
B2AB28
Z26BA53
BB54

This works like a number system with base 26, except the letters represent values from 1 to 26 instead of 0 to 25.

For example, AB means:

\[1 \times 26 + 2 = 28\]

2. Brute Force Approach

We could generate Excel column names sequentially, starting from A, until we reach the given title, counting each column along the way.

This is inefficient because we may need to generate a very large number of titles before reaching the target. A direct mathematical calculation is much better, so the optimized solution uses that logic.

3. Optimized Approach — Base 26 Conversion

Intuition

Think of AB as a positional number system. In decimal, 123 is calculated as:

\[1 \times 10^2 + 2 \times 10^1 + 3 \times 10^0\]

Similarly, Excel column titles use base 26:

\[AB = 1 \times 26^1 + 2 \times 26^0 = 28\]

Instead of calculating powers separately, process the string from left to right. For every character:

  1. Multiply the current result by 26.
  2. Convert the character into its numeric value using ch - 'A' + 1.
  3. Add that value to the result.

Java code — Interview-ready solution

public class Solution {
    public int titleToNumber(String A) {
        int result = 0;

        // Process each character from left to right
        for (int i = 0; i < A.length(); i++) {
            char ch = A.charAt(i);

            // Convert A-Z into values 1-26
            int value = ch - 'A' + 1;

            // Shift the previous value by one base-26 position
            result = result * 26 + value;
        }

        return result;
    }
}

Understanding the important line

int value = ch - 'A' + 1;

Characters have numeric character codes. Subtracting 'A' gives a zero-based offset, so we add 1 to get the Excel value.

Character Calculation Value
A'A' - 'A' + 11
B'B' - 'A' + 12
Z'Z' - 'A' + 126

4. Dry Run of the Optimized Solution

Input: AB

Initially, result = 0.

Step Character Value Calculation Result
1A1\(0 \times 26 + 1\)1
2B2\(1 \times 26 + 2\)28

Output: 28

Input: BB

Step Character Value Calculation Result
1B2\(0 \times 26 + 2\)2
2B2\(2 \times 26 + 2\)54

Output: 54

Why multiply by 26? Every new character moves the previous value one position to the left in base 26. Multiplying by 26 makes room for the next character.

5. Complexity Analysis

Let \(N\) be the length of the column title.

Approach Time complexity Auxiliary space
Brute force using positional powers\(O(N^2)\)\(O(1)\)
Optimized iterative conversion\(O(N)\)\(O(1)\)
  • Brute force: Calculate each character's positional power separately, requiring repeated multiplications.
  • Optimized: Visit each character exactly once.
  • Auxiliary space: Both approaches use only a constant number of variables.

The optimized approach is the recommended solution.

8. Interview Preparation Notes

Pattern to remember: Positional number conversion using the Horner-style recurrence:

\[\text{result}=\text{result}\times26+\text{value}\]

Common mistakes

  • Using ch - 'A' without adding 1.
  • Forgetting to multiply the existing result by 26.
  • Treating Excel columns as ordinary zero-based base 26.

Likely interviewer follow-up questions

Q1. Why is this base 26 rather than base 27?

There are 26 letters. Each position contributes a value from 1 through 26; there is no zero-valued letter.

Q2. How would you solve the reverse problem?

Repeatedly subtract 1, take the remainder modulo 26, convert that remainder to a letter, and divide by 26. Subtracting 1 handles the fact that Excel's numbering is 1-based.

Q3. What is the maximum value with a title length of 5?

ZZZZZ corresponds to:

\[26+26^2+26^3+26^4+26^5=12{,}356{,}630\]

This fits within Java's int range.

9. Final Recommendation

Use the optimized iterative solution in interviews. It is simple, efficient, and processes every character once.

  • Time: \(O(N)\)
  • Auxiliary space: \(O(1)\)
Remember: Multiply the current result by 26, then add the current letter's value.
