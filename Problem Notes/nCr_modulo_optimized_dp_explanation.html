Calculate nCr mod m Using Dynamic Programming

A beginner-friendly explanation of the symmetry property, one-dimensional Pascal's Triangle DP, and a complete dry run in Java.

1. Problem understanding

You are given three integers: A = n (total items), B = r (items to select), and C = m (modulo value). Return the number of ways to choose B items from A, modulo C.

nCr = n! / (r! × (n − r)!)   and the required answer is nCr mod m

Example: A = 5, B = 2, C = 13. Since 5C2 = 10, the result is 10 % 13 = 10.

Why not calculate factorials? Factorials grow very quickly and overflow Java integer types. Instead, calculate combinations from smaller combinations using DP.

2. Useful nCr property: symmetry

nCr = nC(n − r)

Selecting r items to include is equivalent to selecting the remaining n − r items to leave out. Therefore, use the smaller value:

int r = Math.min(B, A - B);

For example, if A = 100 and B = 98, then r = min(98, 2) = 2. We only need to calculate combinations up to 2 instead of 98.

3. Optimized solution: one-dimensional DP

Pascal's Triangle gives us this recurrence:

C(i, j) = C(i − 1, j) + C(i − 1, j − 1)

In plain language, choosing j items from i items means either excluding the newest item (choose j from i − 1) or including it (choose j − 1 from i − 1). Add those possibilities and take the modulo.

Complete Java code

public int solve(int A, int B, int C) {

    // Use nCr = nC(n-r) to minimize the DP array size.
    int r = Math.min(B, A - B);

    // dp[j] stores the current number of ways to choose j items,
    // modulo C.
    int[] dp = new int[r + 1];

    // There is one way to choose zero items.
    // This also handles C = 1.
    dp[0] = 1 % C;

    // Build combinations for each i from 1 through A.
    for (int i = 1; i <= A; i++) {

        // Update backward so dp[j-1] still belongs to the previous row.
        for (int j = Math.min(i, r); j >= 1; j--) {

            // Pascal's Triangle recurrence, with modulo applied each time.
            dp[j] = (int) (((long) dp[j] + dp[j - 1]) % C);
        }
    }

    // By symmetry, ACr is the same as ACB.
    return dp[r];
}

How the code works

  1. Reduce r: Math.min(B, A - B) uses symmetry to reduce the amount of work.
  2. Initialize: dp[0] = 1 % C, because there is exactly one way to choose nothing.
  3. Build each row: The outer loop processes values from 1 to A.
  4. Update backward: The inner loop goes from min(i, r) down to 1, preserving values from the previous row.
  5. Apply modulo: Each value remains between 0 and C - 1. The long cast makes the addition safe.
  6. Return: dp[r] is the requested combination modulo C.

So the DP array has r + 1 = 3 entries.

At the end, r = 2, so we return dp[2] = 10. Thus, 5C2 % 13 = 10.

5. Why must the inner loop run backward?

Before processing i = 3, the array is [1, 2, 1]. We must calculate dp[2] using the old dp[1] = 2:

dp[2] = (1 + 2) % 13 = 3

If we updated left to right, dp[1] would first become 3, and then dp[2] would incorrectly become (1 + 3) % 13 = 4. Backward updates preserve the previous row's values.

6. Complexity analysis

Let k = min(B, A - B).

  • Time: O(A × k), because at most k DP entries are updated for each of the A rows.
  • Auxiliary space: O(k), because the solution stores one array of size k + 1.

The constraints guarantee A × B ≤ 10⁶, so the number of DP updates is within a practical range.

8. Interview takeaways

  1. Symmetry: nCr = nC(n-r); use the smaller selection count.
  2. Pascal's Triangle: Calculate combinations by adding smaller combinations, avoiding factorial overflow.
  3. Backward updates: Preserve the previous row while using a one-dimensional DP array.
  4. Modulo: Applying modulo after each addition works for any positive modulus, including composite values; no modular inverse is needed.
Final answer for the dry run: solve(5, 2, 13) returns 10. If a judge reports a different expected result, check the exact values of A, B, and C supplied to the failing test.
